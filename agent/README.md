# SAP LiveKit AI Agent

## Install

```bash
cd agent
npm install
```

## Configure

Create `.env`:

```env
LIVEKIT_URL=
LIVEKIT_API_KEY=
LIVEKIT_API_SECRET=
OPENAI_API_KEY=
```

## Run Agent

```bash
npm run dev
```

## Recommended Hosting

- Railway
- Render
- Fly.io
- VPS

This agent powers realtime SAP voice AI conversations.
